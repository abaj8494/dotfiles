* Distrotube's Emacs Configuration Analysis

** Overview

Derek Taylor's (DistroTube) Emacs configuration is a literate programming setup using org-babel.
The entire configuration lives in a single =config.org= file (~1,161 lines) that tangles to =config.el=.

Repository: https://gitlab.com/dwt1/dotfiles (=.config/emacs/=)

#+begin_example

** Org-Babel Tangling Pattern

*** The init.el Loader

The entire =init.el= is just:

#+begin_src emacs-lisp :tangle no
(org-babel-load-file
 (expand-file-name "config.org" user-emacs-directory))
#+end_src

*** config.org Header

#+begin_src org :tangle no
,#+TITLE: DT's GNU Emacs Config
,#+AUTHOR: Derek Taylor (DT)
,#+STARTUP: showeverything
,#+OPTIONS: toc:2
#+end_src

*** Code Block Pattern

Each section contains prose documentation followed by code:

#+begin_src org :tangle no
,* SECTION NAME
Description of what this section does and why.

,#+begin_src emacs-lisp
;; Actual elisp code here
,#+end_src
#+end_src

*** Scripts Directory Pattern

Large standalone utilities go in =scripts/= and are loaded via:

#+begin_src emacs-lisp :tangle no
(add-to-list 'load-path "~/.config/emacs/scripts/")
(require 'elpaca-setup)
(require 'buffer-move)
(require 'app-launchers)
#+end_src

** Dashboard (Startup Screen)

The =dashboard= package provides a rich startup buffer with quick access to:
- Recent files
- Agenda items
- Bookmarks
- Projects

*** Installation

#+begin_src emacs-lisp :tangle no
(use-package dashboard
  :straight t
  :init
  (setq initial-buffer-choice 'dashboard-open
        dashboard-set-heading-icons t
        dashboard-set-file-icons t
        dashboard-banner-logo-title "Welcome, Aayush!"
        dashboard-startup-banner 'logo  ; or path to image
        dashboard-center-content nil
        dashboard-items '((recents   . 5)
                          (agenda    . 5)
                          (bookmarks . 3)
                          (projects  . 3)))

** Perspective (Workspaces)

The =perspective= package provides named workspaces with isolated buffer lists.

*** Key Features
- Each perspective has its own buffer list
- Switch between perspectives by name
- Sessions persist across restarts
- Integrates with ibuffer for filtering

*** Installation

#+begin_src emacs-lisp :tangle no
(use-package perspective
  :straight t
  :custom
  (persp-mode-prefix-key (kbd "C-c M-p"))
  :init
  (persp-mode)
  :config
  (setq persp-state-default-file
        (expand-file-name "sessions" user-emacs-directory)))
#+end_src

*** Distrotube's Keybindings

| Key | Command | Description |
|-----|---------|-------------|
| =C-c M-p s= | persp-switch | Switch/create perspective |
| =C-c M-p k= | persp-remove-buffer | Remove buffer from perspective |
| =C-c M-p c= | persp-kill | Kill a perspective |
| =C-c M-p r= | persp-rename | Rename perspective |
| =C-c M-p a= | persp-add-buffer | Add buffer to perspective |
| =C-c M-p A= | persp-set-buffer | Set buffer to only this perspective |
| =C-c M-p b= | persp-switch-to-buffer | Switch buffer within perspective |
| =C-c M-p i= | persp-import | Import buffers from another perspective |
| =C-c M-p n/p= | persp-next/prev | Cycle perspectives |

*** Use Cases
- Separate workspaces for: email, coding, writing, org-roam
- Quick context switching without buffer clutter
- Save/restore workspace layouts

* Refactoring Roadmap

** Goal

Convert modular =elisp/*.el= structure to single =config.org= with org-babel tangling.

** Phase 1: Infrastructure

*** Create New Directory Structure

#+begin_example

├── init.el              # Simplified to 3 lines
├── early-init.el        # Keep as-is
├── config.org           # New main config

* Quick Reference: Org-Babel Tangle Syntax

** Default Tangle Header

Put in config.org header to tangle all blocks to config.el:

#+begin_src org :tangle no
,#+PROPERTY: header-args:emacs-lisp :tangle config.el :results silent
#+end_src

** Per-Block Override

Don't tangle a specific block:

#+begin_src org :tangle no
,#+begin_src emacs-lisp :tangle no
;; This code won't be tangled
,#+end_src
#+end_src

Tangle to a different file:

#+begin_src org :tangle no
,#+begin_src emacs-lisp :tangle "scripts/custom.el"
;; Goes to scripts/custom.el
,#+end_src
#+end_src

** Useful Org-Babel Settings

#+begin_src emacs-lisp :tangle no
;; Preserve indentation when tangling
(setq org-src-preserve-indentation t)

;; Don't ask for confirmation when evaluating
(setq org-confirm-babel-evaluate nil)

;; org-tempo for quick block insertion (<s TAB)
(require 'org-tempo)
#+end_src
