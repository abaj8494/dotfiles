\section{Distrotube's Emacs Configuration Analysis}
\label{sec:org82e4876}

\subsection{Overview}
\label{sec:org396c1b6}

Derek Taylor's (DistroTube) Emacs configuration is a literate programming setup using org-babel.
The entire configuration lives in a single \texttt{config.org} file (\textasciitilde{}1,161 lines) that tangles to \texttt{config.el}.

Repository: \url{https://gitlab.com/dwt1/dotfiles} (\texttt{.config/emacs/})
\subsection{File Structure}
\label{sec:org81f6738}

\begin{verbatim}
.config/emacs/
├── init.el                 # 4 lines - just loads config.org
├── early-init.el           # Disables package.el
├── config.org              # Main literate config (1,161 lines)
├── config.el               # Auto-generated from config.org
├── start.org               # Help/reference document
├── scripts/                # Modular elisp helpers
│   ├── elpaca-setup.el     # Package manager bootstrap
│   ├── app-launchers.el    # dmenu-like launcher
│   ├── buffer-move.el      # Window movement utilities
│   └── eshell-prompt.el    # Custom eshell prompt with git
├── themes/
│   └── dtmacs-theme.el     # Custom theme
├── eshell/
│   ├── aliases             # Shell aliases
│   └── profile             # Startup commands
└── images/
    └── dtmacs-logo.png     # Dashboard logo
\end{verbatim}
\subsection{Org-Babel Tangling Pattern}
\label{sec:org7da1ad3}

\subsubsection{The init.el Loader}
\label{sec:orgebefe98}

The entire \texttt{init.el} is just:

\begin{verbatim}
(org-babel-load-file
 (expand-file-name "config.org" user-emacs-directory))
\end{verbatim}
\subsubsection{config.org Header}
\label{sec:orgd861def}

\begin{verbatim}
#+TITLE: DT's GNU Emacs Config
#+AUTHOR: Derek Taylor (DT)
#+STARTUP: showeverything
#+OPTIONS: toc:2
\end{verbatim}
\subsubsection{Code Block Pattern}
\label{sec:orge3849a6}

Each section contains prose documentation followed by code:

\begin{verbatim}
* SECTION NAME
Description of what this section does and why.

#+begin_src emacs-lisp
;; Actual elisp code here
#+end_src
\end{verbatim}
\subsubsection{Scripts Directory Pattern}
\label{sec:org16114f0}

Large standalone utilities go in \texttt{scripts/} and are loaded via:

\begin{verbatim}
(add-to-list 'load-path "~/.config/emacs/scripts/")
(require 'elpaca-setup)
(require 'buffer-move)
(require 'app-launchers)
\end{verbatim}

\subsection{Perspective (Workspaces)}
\label{sec:org0812d00}

The \texttt{perspective} package provides named workspaces with isolated buffer lists.
\subsubsection{Key Features}
\label{sec:org3cfa988}
\begin{itemize}
\item Each perspective has its own buffer list
\item Switch between perspectives by name
\item Sessions persist across restarts
\item Integrates with ibuffer for filtering
\end{itemize}
\subsubsection{Installation}
\label{sec:orgd0c1300}

\begin{verbatim}
(use-package perspective
  :straight t
  :custom
  (persp-mode-prefix-key (kbd "C-c M-p"))
  :init
  (persp-mode)
  :config
  (setq persp-state-default-file
        (expand-file-name "sessions" user-emacs-directory)))
\end{verbatim}

\section{Quick Reference: Org-Babel Tangle Syntax}
\label{sec:orgd03293d}

\subsection{Default Tangle Header}
\label{sec:org121a1dc}

Put in config.org header to tangle all blocks to config.el:

\begin{verbatim}
#+PROPERTY: header-args:emacs-lisp :tangle config.el :results silent
\end{verbatim}
\subsection{Per-Block Override}
\label{sec:orgf0c8481}

Don't tangle a specific block:

\begin{verbatim}
#+begin_src emacs-lisp :tangle no
;; This code won't be tangled
#+end_src
\end{verbatim}

Tangle to a different file:

\begin{verbatim}
#+begin_src emacs-lisp :tangle "scripts/custom.el"
;; Goes to scripts/custom.el
#+end_src
\end{verbatim}
\subsection{Useful Org-Babel Settings}
\label{sec:org36ba729}

\begin{verbatim}
;; Preserve indentation when tangling
(setq org-src-preserve-indentation t)

;; Don't ask for confirmation when evaluating
(setq org-confirm-babel-evaluate nil)

;; org-tempo for quick block insertion (<s TAB)
(require 'org-tempo)
\end{verbatim}
